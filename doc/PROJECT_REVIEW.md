# プロジェクトレビュー（2026-09-05）

CinemaはmacOS 14以降を対象とする、映画・映像制作のプリプロダクション用ドキュメントアプリです。SwiftUIの編集画面から作品設定・Scene State・カット・リファレンスを編集し、AIによるプレビュー生成と外部推論用Scene Bundle出力へつなぎます。現状の用途ではバックエンドサーバーの追加は不要です。

データは `StoryboardDocument` が保持し、`storyboard.json` と画像・旧形式の埋め込み動画をFileWrapperで保存します。新しい生成動画は書類の隣の `movies/` に保存し、書類には相対参照を記録します。APIキーはKeychain、画面比率は作品書類に保持し、プロバイダなどの共通設定はAppStorageにあります。
